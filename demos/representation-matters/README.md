# Demo 05 — Representation Matters

This static browser demonstration compares several encodings of the same source scene and asks whether each encoding preserves the evidence required by a declared question.

It teaches:

```text
source observation + evidence question + representation
→ evidence preserved or evidence lost
```

Questions cover direction, exact distance, and visible identity. Representations include a full spatial grid, pooled summary, max aggregation, and an identity-free view.

The demo is an explanatory reconstruction of ZeroModel's representation findings. It does not reproduce the complete benchmark or measured compiler evaluation.
