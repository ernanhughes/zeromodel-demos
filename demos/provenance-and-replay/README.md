# Demo 10 — Provenance and Replay

Shows an immutable artifact identity, ordered operation chain, source ownership, tamper detection, and bounded deterministic replay.

## Cases

- verified artifact replaying to a matching hash;
- altered derivative replaying to the original and exposing mismatch;
- incomplete chain stopping replay.

This is an explanatory browser reconstruction aligned with ZeroModel provenance and observation-ledger concepts, not the production persistence stack.
