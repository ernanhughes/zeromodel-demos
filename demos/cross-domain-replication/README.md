# Demo 08 — Cross-Domain Replication

This static browser demo applies the same transition-contract shape to two unrelated domains:

- an arcade ship transition;
- a warehouse crate transition.

It demonstrates that component-change and directional-relation contracts can transfer structurally, while exact values and identity depend on domain evidence.

The ZeroModel idea is **cross-domain contract replication**: reuse the contract grammar, not the domain-specific vocabulary.

This is a bounded explanatory reconstruction and does not reproduce the complete production cross-domain benchmark.

Run from the repository root and open `/demos/cross-domain-replication/`.
