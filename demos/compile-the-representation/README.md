# Demo 06 — Compile the Representation

This static browser demonstration starts from an evidence contract and evaluates a bounded set of candidate representations.

It teaches:

```text
evidence requirement
→ candidate representations
→ reject evidence-losing candidates
→ select lowest-cost passing artifact
```

The candidates are deliberately simple explanatory encodings. The demo reflects the Evidence Contract Compiler idea but does not reproduce the complete production compiler, benchmark search, or measured results.
