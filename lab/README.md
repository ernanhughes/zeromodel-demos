# Lab

The lab contains interactive technical tools for inspecting, comparing, and manipulating ZeroModel artifacts.

Labs may evolve quickly, but they should still be useful and runnable. They are the bridge between raw experiments and stable public demonstrations.

## Suitable lab projects

- VPM viewers and address explorers;
- representation comparison workbenches;
- transition-contract inspectors;
- evidence overlay tools;
- release-manifest and artifact browsers;
- manual-versus-compiled representation comparisons.

## Planned labs

- `representation-failure-explorer`
- `visual-evidence-inspector`
- `vpm-address-browser`

## Stability expectations

Labs may change interfaces between revisions. Each lab must nevertheless state:

- the ZeroModel version or commit it targets;
- its data and artifact inputs;
- how to reproduce its default view;
- which outputs are diagnostic rather than validated product claims;
- whether it is a candidate for promotion to `demos/` or `showcase/`.
